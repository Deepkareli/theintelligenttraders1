All on same browser · No server needed
ℹ Everything uses browser localStorage — no server, no API, no cost. Works instantly. Data persists until browser cache is cleared. Works across tabs in the same browser.
01
Dashboard
User enters market data once. On "Run Analysis", bridge saves ALL fields to shared storage. Becomes the single source of truth.
02
Algo Tool
Loads → auto-fills all 13 fields from bridge. After analysis runs, saves trigger output (T1–T6), confluence score, SL, Target back to bridge.
03
Journal
When logging a trade, auto-fills VIX, IV Rank, triggers fired, recommended SL/Target, and current capital phase — zero re-entry.

📁 Step 1 — Add it-bridge.js to your project

Copy the it-bridge.js file into your website's root folder (same level as dashboard.html, journal.html, algo.html).

✅ The bridge file is included in the download. Place it at: /it-bridge.js (website root)

📊 Step 2 — Wire dashboard.html

dashboard.html (or ai-engine page)

A) Add the script tag

Paste this just before your closing </body> tag:

<script src="/it-bridge.js"></script>

B) Add a sync bar host div

Find the main wrapper div in your dashboard HTML. Add id="sync-bar-host" to it, or add this div just inside your form section:

<!-- Add this div just above your market data form -->
<div id="sync-bar-host"></div>

C) Save data when user clicks "Run Analysis"

Find the button or function that triggers analysis. Add ONE line to save market data before running:

// Find your existing "Run Analysis" click handler and add this line at the top:

document.querySelector('[onclick*="runAnalysis"], #runBtn, .run-btn')
  .addEventListener('click', function() {

  // ← ADD THIS LINE (saves all form fields to bridge)
  ITBridge.collectDashboard();

  // ... rest of your existing analysis code ...
});

D) Save signal output when analysis completes

Find where your analysis result is rendered. After you have the trigger results, add:

// After your trigger detection logic runs, add this call:
ITBridge.saveSignal({
  triggers:        firedTriggers,      // array like ['T1 VaR Breach', 'T5 IV Crush']
  confluenceScore: confluenceScore,    // number 0-100
  recSize:         recommendedSize,    // ₹ amount
  stopLoss:        stopLossPrice,      // ₹ premium
  target:          targetPrice,        // ₹ premium
  recType:         'Long Call',        // trade type suggestion
  rationale:       aiRationale,        // text from AI report
});
⚠ If your analysis variables have different names, just map them. The key thing is calling ITBridge.saveSignal() after triggers are detected.

⚡ Step 3 — Wire algo.html

algo.html

A) Add the script tag

<script src="/it-bridge.js"></script>

B) Add sync bar host

<!-- Add just above your market data input panel -->
<div id="sync-bar-host"></div>

C) Add an "Auto-fill from Dashboard" button

The sync bar already has an auto-fill button. But you can also add a standalone button next to your form:

<button onclick="ITBridge.fillAlgo()" class="your-existing-btn-class">
  ⬇ Load from Dashboard
</button>

D) Save trigger results after Algo runs

Find where your algo outputs triggers/confluence. Add the same saveSignal call:

// In your algo's "RUN ANALYSIS" output handler:
ITBridge.saveSignal({
  triggers:       algoFiredTriggers,
  confluenceScore: algoConfluence,
  recSize:        algoRecSize,
  stopLoss:       algoStopLoss,
  target:         algoTarget,
});

📓 Step 4 — Wire journal.html

journal.html

If using the new journal.html we built — it already has full bridge integration built in. Just add the script tag:

<script src="/it-bridge.js"></script>

If using your existing journal.html, add the script tag AND add a sync bar host div, then add this button to your "Log New Trade" form:

<!-- Add this button at the top of your Log Trade form -->
<button onclick="ITBridge.fillJournal()" type="button">
  ⬇ Auto-fill from today's Dashboard analysis
</button>

<!-- And add sync-bar-host somewhere visible -->
<div id="sync-bar-host"></div>

Save capital updates back to bridge

When a trade is closed and capital changes, update the bridge:

// After closing a trade and updating capital in your journal logic:
ITBridge.saveCapital(newCapitalAmount, currentPhase);
// e.g.: ITBridge.saveCapital(27500, 1);

✅ Step 5 — Test the flow

Test checklist:

1. Open Dashboard → enter market data → click Run Analysis
2. Check: green sync bar appears with today's data ✅
3. Open Algo in a new tab → check: fields auto-filled ✅
4. Run Algo analysis → check: triggers saved ✅
5. Open Journal → click "Log New Trade" → check: VIX, IVR, trigger checkboxes pre-filled ✅
6. Close a trade → check: capital updates in sync bar on all pages ✅

🔧 Troubleshooting

ProblemFix
Sync bar not appearingAdd id="sync-bar-host" to your main wrapper div
Fields not auto-fillingYour input IDs may differ — check browser console for field mapping. Edit fieldMap in it-bridge.js
Data not persistingUser cleared browser cache/localStorage. Normal — re-enter on Dashboard
Works in one tab but not anotherBoth pages must load it-bridge.js. Check script tag on each page
Netlify shows old versionHard refresh (Ctrl+Shift+R) after deploying. Netlify may cache JS files
